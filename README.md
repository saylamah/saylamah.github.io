# Ahmad Saylam — Scientific & Engineering Knowledge Website

Source repository for the public scientific and engineering website:

**https://saylamah.github.io**

The website presents selected public and non-confidential scientific, engineering and professional evidence across:

- applied physical chemistry, thermodynamics and chemical kinetics;
- combustion, reactive systems, soot and nanoparticle inception;
- reactor modelling, CFD and multiscale analysis;
- thermochemical conversion, biomass, biochar, syngas and waste-to-X;
- fuels, desulfurization and process intensification;
- advanced oxidation processes and wastewater treatment;
- technology development, model verification, experimental validation, pilot development and industrial scale-up.

## Website Role

The website is the public interface to a broader scientific and engineering knowledge system.

Its purpose is to connect, without unnecessary duplication:

- peer-reviewed publications and open technical outputs;
- reproducible GitHub repositories and software archives;
- selected evidence-backed engineering case studies;
- research methods and development frameworks;
- professional evidence and career context;
- employment, scientific collaboration and consulting pathways.

The website follows a contribution-first communication principle:

**Contribution → Methodology → Evidence → Application → Biography**

It is not intended to function only as an online CV, publication catalogue or consulting brochure. The emphasis is on technically useful, evidence-linked scientific and engineering resources.

## Knowledge Architecture

Public technical material is organized as reusable scientific and engineering resources rather than as a bulk archive.

A scientific or engineering contribution may have several controlled public representations, for example:

- peer-reviewed publication or technical paper;
- GitHub repository;
- Zenodo or software archive;
- website technical page or case study;
- modelling, verification or validation method;
- educational resource;
- professional or consulting application.

These representations are linked where useful, while their evidence status and purpose remain distinct.

Current public technical areas include:

- nanoparticle-inception hypothesis and persistence/stabilization modelling;
- desulfurization reaction–transport analysis;
- matrix-aware advanced-oxidation-process development;
- combustion kinetics, mechanism reduction and reaction-network analysis;
- high-pressure combustion diagnostics and multiscale modelling;
- thermochemical and biomass-process modelling reconstruction;
- technology-development, validation and scale-up methodology.

A cross-domain technology-development methodology is maintained in the Research & Tools layer and supported by dedicated scale-up and thermochemical-development outputs.

## Evidence and Provenance Policy

Public content is selected rather than bulk-published.

Historical programs, mechanisms, figures, datasets and project materials are reviewed for:

- authorship and ownership;
- confidentiality;
- licensing and redistribution rights;
- technical integrity;
- evidence maturity;
- applicability boundaries;
- suitability for public communication.

The website does not intentionally disclose confidential client or employer information, restricted operating data, proprietary project details or third-party material without an appropriate right to use it.

Evidence levels are kept distinct. In particular:

- software tests and reproducible execution support implementation integrity;
- numerical or model verification checks implementation and computational consistency;
- experiment–model agreement supports only the observables and operating domain actually compared;
- experimental validation requires suitable physical evidence;
- pilot or industrial evidence remains system- and application-specific.

Research hypotheses, screening frameworks, reconstructed models, computational studies, experimental observations, pilot evidence and independently validated results are therefore not treated as equivalent.

## Publication Access and Rights

Local publication files are exposed only when the hosted version and redistribution basis are sufficiently clear.

Where applicable:

- Author Accepted Manuscripts are labelled explicitly;
- publisher Versions of Record are not presented as locally hosted copies unless rights permit;
- DOI links point to the formal publication record;
- publication summaries are independently written;
- access status does not imply permission for unrestricted reuse.

Rights-sensitive material remains publisher-linked until the exact self-archiving version and permissions are verified.

## Repositories, DOI Records and Reproducibility

Where appropriate, technical resources are linked to:

- GitHub repositories for transparent implementation;
- Zenodo releases for persistent archival records and DOI assignment;
- publication pages for scientific context;
- Selected Work entries for engineering interpretation.

Reproducibility and software verification are distinguished from experimental or industrial validation.

A repository, software test or computational comparison should not be read as evidence of physical validation unless the corresponding experimental evidence is explicitly identified.

## Development Principles

The website and related repositories are maintained using several long-term principles:

- evidence before claims;
- validation before promotion;
- reuse before duplication;
- one controlled source wherever practical;
- explicit applicability and uncertainty boundaries;
- implementation-defect checks before anomalous-physics explanations;
- traceability between publications, repositories, methods and case studies;
- preservation of scientifically useful legacy work through transparent reconstruction rather than unsupported modernization;
- confidentiality and intellectual-property boundaries before public disclosure.

## Pre-Release Control

Technical material under active development is not exposed publicly merely because it exists in a working repository or archive.

New repositories, DOI records, release links and public claims are added only when the corresponding release or publication gate has been completed. This README therefore describes only the current public state of the website.
